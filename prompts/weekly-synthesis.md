# Weekly synthesis

Read `Librarian.md` and `skills/README.md`. Find substantive notes created or updated
in the last seven days using the activity log, git history, note dates, and current
uncommitted additions. Read the actual notes, not only their digests. Exclude
operational docs and previous generated reports as independent source evidence.

Write `03-resources/compound/weekly/YYYY-Www.md` for the current ISO week:
recurring themes, tensions/contradictions, non-obvious connection suggestions, and
open questions. Cite the notes behind every finding. If there is no new substantive
material, write a short honest report rather than manufacturing an insight.

Only if genuine cross-source insight emerges, manually create a thematic synthesis
note in `03-resources/` with created/tags/sources frontmatter; run
`skills/claim-ledger.md`, and index it when the topic qualifies. Read any existing
note first and use `skills/vault-transaction.md` where triggered. Suggest, never
silently adopt, changes to the user's theses. Append completion to the activity log and
refresh Home when its listing changes.

The unattended runner returns only the weekly report. Include proposed synthesis
notes, links, and ledger entries as recommendations inside it. Do not modify other
notes or indexes in that mode; the runner saves the report and appends its activity
line. Never overwrite a previously generated report unattended.
