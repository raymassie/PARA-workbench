# Pattern surfacing

Trigger: “Spark”, “Surface patterns”, or “What's forming”.
Read `skills/README.md`. Inspect dated journal/area notes, `00-raw`, recent
`04-archive/raw` captures, and substantive filed notes from the past fourteen days.
Use explicit capture dates/git history; label unknown dates rather than inventing
a window. Do not use generated reports as independent occurrences.

Look for the same question, phrase, or concern recurring in different wording in
notes that do not already reference one another. Shared subject matter alone is
not a pattern. Quote each actual instance, link its source, state its date and the
range, and name the observation (“You keep circling ...”). Include only patterns
whose combined evidence reveals something new; do not force a minimum count.

Save `03-resources/compound/YYYY-MM-DD-patterns.md`. Offer backlinks only to live
filed notes; never edit raw or archived sources. Use shared logging/indexing rules.
