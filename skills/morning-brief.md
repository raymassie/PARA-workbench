# Morning brief

Trigger: “Morning brief” or “What matters today”. Read `skills/README.md` first.

Read Librarian.md, Home, active project single notes and folder READMEs, relevant
area notes, and the latest explicit dated intentions. Use git history and note
dates to flag projects unchanged for 7+ days as potentially stalled, not proven
abandoned. Report unknown dates honestly. Read today's calendar through
`scripts/read-calendar.py` using the allowlist and limitations in
`skills/calendar-sync.md`; if unavailable, say so and continue.

Write `03-resources/compound/YYYY-MM-DD-morning-brief.md` with:
- The one thing: a specific immediately actionable priority supported by a cited note.
- Today's calendar: timed events in order, all-day events separately; distinguish
  empty schedules from unavailable calendars.
- Open loops: consequential unresolved intentions, with their source notes.
- Project status: one status and next action per active project.
- Decision flags: pending decisions demonstrably open longer than five days.

Keep it readable in under five minutes. Do not manufacture a priority when there
is insufficient evidence. Briefly flag schedule conflicts; deeper reconciliation
belongs to calendar-sync. No event creation. Finish using shared logging/indexing
conventions. The runner's report-only mode is described in `scripts/README.md`.
