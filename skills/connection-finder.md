# Connection finder

Trigger: “Find connections”, or after three new substantive notes when requested.
Read `skills/README.md`. Find filed notes added/changed in the past seven days
across the live buckets, then search other live notes and archived material for
strong connections. Exclude generated reports and operational docs.

A connection must reveal an insight neither note contains alone; sharing a topic
is insufficient. Read both notes fully. For each result name and link both notes,
explain the new insight, and state any action or investigation it suggests.
Omit obvious or unsupported connections; an empty result is valid.

Save `03-resources/compound/YYYY-MM-DD-connections.md`. Add links back from the
live filed source notes only when warranted by the task, after reading them and
using a transaction if needed. Never edit `00-raw` or `04-archive` for backlinks.
Use shared logging/indexing conventions.
