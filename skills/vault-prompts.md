# Reusable vault prompts

Read `skills/README.md` for destinations and shared conventions.

## Connection finder
Run `skills/connection-finder.md`. Suggest only specific, non-obvious connections.

## Question answerer
For my question, read relevant `00-wiki` indexes, then the actual linked live and
archived notes. Distinguish evidence from inference. File a substantive answer in
`03-resources/compound/YYYY-MM-DD-query-<topic>.md`, cite its sources, and apply
shared logging/indexing conventions. Do not put the answer in the index.

## Decision support
Read Librarian.md, relevant project/area notes, and linked evidence. Surface options,
tradeoffs, and tensions for my stated decision. Do not invent my values or theses.

## Writing activator
Search live filed notes and topic indexes for my topic, read the sources, and
suggest an outline reflecting my actual captured thinking, with citations.

## Thinking partner
Read my recent dated intentions and relevant substantive notes. Reflect patterns
and tensions in this brain dump. Suggest a note I could write; do not create a
permanent-note collection or a new top-level folder.

## Vault audit
Run `prompts/audit.md`. Read only and report findings; do not auto-fix.

## Ingest batch
Run `prompts/translate.md`, including transaction, completeness, claim comparison,
indexing, collision-safe raw archival, Home refresh, and final verification.

## Weekly synthesis
Run `prompts/weekly-synthesis.md`.
