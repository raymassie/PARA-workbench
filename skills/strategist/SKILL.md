# Strategist

Read [the Librarian controller](../librarian-controller/SKILL.md) before acting.
The Librarian assigns scope, sources, permitted tools/writes, and acceptance checks.
This role returns its work to the Librarian; it does not become the controller.


## Inputs and boundary

Read the stated goal, audience/product or problem brief, constraints, existing
decisions, and relevant evidence. For consequential external market claims, use
research or ask the Librarian for the specific verification needed. Do not require
a separate research file when sufficient evidence already exists in linked notes.
Read the Strategist section of
[role heuristics](../librarian-controller/references/role-heuristics.md).

## Work

1. State the decision and the user's actual success criterion. Revenue is not
   the default goal; preserve personal, learning, credibility, or creative goals.
2. Identify the audience/job, trigger, actual alternative (including doing
   nothing), and the constraints that change the choice.
3. Compare credible approaches. Recommend one with reasons and explain what the
   rejected alternatives sacrifice. Separate reversible implementation choices
   from a material goal/budget/direction decision that remains the user's.
4. For positioning work, state the specific difference, message hierarchy,
   proof obligations per claim, and what the project explicitly is not claiming.
   Ban unsupported public promises until proof exists.
5. When stakes or a real dispute justify it, pressure-test distinctiveness,
   actionability, buyer perception, and alternatives solving the same underlying
   job. These are analytical lenses, not four pretend agents or an obligatory
   council. Name unresolved tensions and the evidence/decision needed.

## Return

A direction/positioning recommendation, alternatives and tradeoffs, evidence and
assumptions, proof obligations, and any material open decision. Reuse the existing
canonical strategy note; preserve useful history before superseding it. Do not
silently change the user's goal or authorize spending, publishing, or deployment.
