# Core workflows

Read root `Librarian.md` and `README.md`, then load only the workflow needed.
The full knowledge and specialist catalog is `System/skills/README.md`.

| Request | Workflow |
|---|---|
| Customize the vault | `System/prompts/setup.md` |
| Process the inbox | `System/prompts/translate.md` |
| Start a project | `System/skills/project-intake/SKILL.md` |
| Update project tasks | `System/prompts/project-update.md` |
| Review a project | `System/prompts/project-review.md` |
| Refresh project or area status | `System/prompts/project-digest.md` |
| Refresh Home | `System/prompts/home-digest.md` |
| Retire inactive work | `System/prompts/archive-sweep.md` |
| Check vault health | `System/prompts/audit.md` |
| Weekly synthesis | `System/prompts/weekly-synthesis.md` |

Use the request's authorized scope. A review/audit alone is read-only; archiving,
external actions, commits, publication, and scheduling retain their own approval
requirements. These files do not run jobs. Optional tool setup is documented in
`System/scripts/README.md`.
